## 6. 并发写一致性验证（tests/concurrency_test.ps1）

- 方法：20 个 curl 进程并发向同一 CSV 追加 20 条不同名称点位。
- 结果：`total=20 names=20 unique=20`，**无丢失、无重复、文件结构完好**（表头 + 20 数据行，BOM 正常），PASSED。

## 7. 数据文件验证

- 表头：`name,io_address,address_type,point_type,rw,desc`（6 列固定顺序）。
- 编码：UTF-8 带 BOM，Excel 可直接打开无乱码。
- 目录穿越：`../evil` 等文件名在 API 层被拒（400/40002）。

4. PowerShell 5.1 冒烟脚本依赖 `curl.exe`（Windows 10+ 自带）。
