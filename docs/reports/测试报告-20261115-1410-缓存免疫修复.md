## 4. 已知问题

1. 浏览器端最终确认需用户执行：**Ctrl+F5 强刷一次**（清除本次修复前已缓存的旧页面/旧响应），之后点击 TOPIC_1 应显示 2 个点位（aaa、1111）；因修复后所有响应均带 `Cache-Control: no-store`，后续无需再强刷。
2. 若强刷后仍不显示：按 D1 排查第 2/3 步提供 F12 Network 中 `GET /api/v1/points` 的响应码/响应体与 Console `[api]`/`[render]` 日志，将按 D2 重新出方案。
3. 历史浏览器缓存仅对旧 URL 生效；新加 `_ts` 参数使每次 GET URL 唯一，从机制上杜绝再次发生。
