### D1 根因链（证据）

1. 用户错误栈：`Uncaught TypeError: Cannot set properties of null (setting 'textContent') at selectFile ((index):323)`——行号与最新页面代码 `$("curFileLabel").textContent` 一致。
2. 结构缺陷：`curFileLabel` 是 `editHint` 的**子节点**（index.html:186）；`resetForm()` 以 `$("editHint").innerHTML = ...` 整体替换文案，**子节点随之销毁**。
3. 触发链：点击文件 → `selectFile` → `resetForm()`（销毁节点）→ `$("curFileLabel")` = null → TypeError → **`reloadPoints()` 不执行** → 表格停留原状。
4. 影响面：`appendPoint/updatePoint` 成功回调同样经 `selectFile` 刷新——**最初"添加点位后看不到数据"的真正根因即此**（14:10 的缓存修复仍有效但非该症状根因）。
5. 佐证：错误栈行号与最新构建吻合 → 用户已在运行新页面，排除缓存/旧副本干扰。
