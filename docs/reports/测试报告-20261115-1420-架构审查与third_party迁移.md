## 4. 已知问题

1. **MSVC C4819 已修复**（根因：UTF-8 无 BOM 源码含中文注释，MSVC 默认按代码页 936 误读导致代码行边界破坏）。修复方式为 CMakeLists 对 MSVC 增加 `/utf-8`（不改动源文件、不加 BOM）。
2. **CMake 4.5.0 对本项目 cmake_minimum_required(VERSION 3.12) 提示 deprecation**（不影响构建）；多配置生成器下 `-DCMAKE_BUILD_TYPE` 为 unused-cli 警告（正常，构建类型由 --config 指定）。
3. `build-vs/` 与 `build/` 为两套独立构建目录（VS 生成器与 MinGW 缓存互不兼容，不能共用），切换工具链时须使用对应目录；`run_tests.py` 依赖 `build/`（MinGW），不受 build-vs 影响。
4. third_party 迁移采用 robocopy 文件级复制（非同盘 rename 级原子操作），完整性以关键文件核对 + 文件计数 + 全量重建回归三重验证替代原子性保证。
