# 测试报告 — 构建产物统一输出到 build 根（tagledger.exe 不再散落于子目录）

- 时间：2026-11-15 19:05
- 性质：构建配置 + 脚本修改（R 系列已走：方案 A/B 对比 → 人工确认方案 B → 编码，R4 留痕于变更日志）

## 1. 测试范围

**背景**：用户报告 `cmake-debug.bat 没有生成 tagledger.exe`。排查结论：S 系列目录重组后 `tagledger` 为 `apps/tagledger/` 子目录 target，MinGW 单配置下默认输出 `build/apps/tagledger/tagledger.exe`，而脚本注释仍写 `build\tagledger.exe`（更名时未同步路径）造成误导。

**改动内容**（按人工确认的方案 B）：
1. `CMakeLists.txt`：单配置生成器增设 `CMAKE_RUNTIME_OUTPUT_DIRECTORY=${CMAKE_BINARY_DIR}`（else 分支）；多配置（VS）分支保持 `build-vs/<Config>/` 不变
2. `tests/scripts/run_tests.py`：`find_exe` 改为 build 根优先、子目录路径仅作兼容回退
3. `tests/scripts/graceful_shutdown_test.py`：`--exe` 默认值改为 `build/tagledger.exe`（含用法注释）
4. `.vscode/launch.json`：MinGW 主程序调试路径 → `${workspaceFolder}/build/tagledger.exe`
5. `README.md`：运行命令 → `.\build\tagledger.exe`
6. 删除旧位置陈旧产物 `build/apps/tagledger/tagledger.exe`
7. `cmake-debug.bat`：注释 `build\tagledger.exe` 方案 B 后成为事实，**未改动**（无 diff，不涉及文件）

**不在本次范围**：launch.json 中 gdb 调试器路径（仍指旧 8.1.0，属既有遗留问题，见"已知问题"2）；MSVC 输出布局；docs/02/05/06（grep 核实无产物路径引用，无需 P4 同步）。

## 2. 测试方法

```powershell
# ① MinGW Debug 重建（重配置 + 并行构建，jobs=4）
.\cmake-debug.bat 4          # 预期 exit 0
# ② 全套测试（跳过性能基准；含单元/[shutdown]/冒烟/并发/优雅退出）
python tests\scripts\run_tests.py --skip-perf    # 预期 exit 0
# ③ MSVC Debug 重建（多配置分支回归确认）
.\vs-debug.bat 4             # 预期 exit 0
# ④ 产物核对
dir /b build\tagledger.exe build\tagledger_tests.exe build\web build\config
```

环境：Windows 10 19045；MinGW GCC 16.2.0（C:\mingw64）；CMake 4.5.0；VS 2019 BuildTools（MSVC 19.29）；Python 3.7。

## 4. 已知问题

1. **`build\apps\tagledger\` 目录仍残留 CMake 中间文件**（Makefile2 等，非 exe）：无运行影响；下次全新重建（删 build/）自然消失。find_exe 已不再回退命中该路径下的 exe（已删除）。
2. **`.vscode/launch.json` 的 gdb 调试器路径仍指向旧 8.1.0**（`C:\Program Files\mingw-w64\...\8.1.0...\gdb.exe`，该工具链已卸载）：既有遗留问题（18:32 前已存在），本次仅按确认范围改产物路径；gdb 路径需另行确认后更新为 `C:\mingw64\bin\gdb.exe`（两处配置）。
3. **历史文档/报告中的 `build/apps/tagledger/tagledger.exe` 路径陈述**：属历史事实记录（changelog 迁移件与 docs/reports 历史报告），按"历史不可回改"原则保留。
4. **CMake 最低版本仍为 3.12**：本次改动仅用 3.12 即有的 `CMAKE_RUNTIME_OUTPUT_DIRECTORY` 与生成器表达式，未抬高门槛（已实测 CMake 4.5.0 正常）。
