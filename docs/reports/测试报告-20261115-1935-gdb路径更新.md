## 4. 已知问题

1. **gdb 内嵌 Python 启动报错**：`Error in sitecustomize ... ImportError: DLL load failed while importing _ctypes`。根因：当前环境 `PYTHONPATH` 指向 CodeBuddy 扩展 shim 目录（`...coding-copilot-.../out/vendor/shim`），gdb 内嵌 Python 拾取后 `_ctypes` 加载失败。**gdb 核心调试功能不受影响**（断点/单步/打印均正常）；pretty-printing 等增强功能可能失效。若在 VSCode 调试时复现并困扰使用，可在 launch.json 对应配置的 `environment` 中加 `{"PYTHONPATH": ""}` 清空规避（本次未改，超出确认范围）。
2. **cmd 单行调用 gdb 的引号转义陷阱**：`-ex` 参数含空格时经 cmd 双层引号会碎裂（本次实测复现两次），验证/脚本场景一律使用 `-x <命令文件>` 传入。对 IDE 内调试无影响。
3. **测试影响范围**：`.vscode/launch.json` 为编辑器调试配置，不影响构建产物与运行时行为；项目代码零改动，无需运行测试套件。
