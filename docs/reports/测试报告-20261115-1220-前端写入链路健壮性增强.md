### 交付内容与需求对照

| 缺陷点（分析结论） | 修复内容 |
| --- | --- |
| 无加载态、可重复提交 | `setWriteBusy()`：请求期间禁用按钮，文案"写入中…/保存中…" |
| 刷新链路竞态（refreshFiles+selectFile 双路径） | 抽出 `reloadPoints()`，成功回调单链路"提示→reloadPoints→refreshFiles" |
| 错误可见性弱 | `api()` 网络错误兜底 + 失败请求 `console.error`（路径+完整响应）；`errText` 区分无错误码场景 |
| 渲染异常/空数据被吞 | `renderTable` 三态（加载中/加载失败/文件为空）+ 防御性取值 + try/catch 异常占位 |
| 新增数据不可辨识 | 按后端返回 index 高亮新行（`tr.highlight` 样式） |
