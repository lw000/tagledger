## 4. 已知问题

1. **旧行为差异（语义保持声明）**：原 main 直接持有 `httplib::Server` 与监听线程；现由 HttpServer::Impl 承载，对外行为（绑定失败→request_stop→退出码 1、stop 排空在途请求）经集成测试等价验证。
2. **HttpServer 未继承 ServiceBase**：按 B1 提炼门槛（≥2 处重复生命周期逻辑才提炼），当前仅一个有启停语义的服务，以六要素**语义**实现（init/start/stop）；出现第二个子服务时再按 B 系列评估提炼，届时 HttpServer 公开头应零改动（B2 反向验收）。
3. **build-vs 旧结构缓存已清理**：本次重组后 build-vs 首次构建前删除了旧缓存（CMake 不支持跨目录结构复用缓存）；后续 vs-*.bat 增量构建正常。
4. **pimpl 引入一次堆分配**：HttpServer 每进程一次，无热路径影响。
5. MinGW `build/` 与 VS `build-vs/` 为两套独立目录（生成器缓存互不兼容），切换工具链须用对应目录与脚本。
