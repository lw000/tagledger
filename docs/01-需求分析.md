# 01 需求分析 — 工业点位采集编辑工具 HTTP 服务

## 1. 项目背景

工业自动化场景中，上位机/网关需要维护一张"点位表"（采集点配置），描述每个采集点的名称、IO 地址、地址类型、数据类型与读写属性。本服务为点位采集编辑工具提供后端支撑：

- 以 CSV 文件为持久化载体（便于与组态软件、PLC 配置工具交换）。
- 对外提供 HTTP REST 接口，支撑单点/批量的读、写操作。
- 内置白名单中间件，限制访问来源，适配工业内网的安全要求。
- 提供一个纯原生 Web 技术实现的前端页面，直接在浏览器中完成点表的编辑。

## 2. 用户与使用方式

| 角色 | 使用方式 |
| --- | --- |
| 现场/维护工程师 | 通过浏览器打开前端页面，选择或新建 CSV 点表文件，增改点位并保存 |
| 组态软件/脚本 | 通过 REST API 读写点表（如导出后批量写入） |
| 运维人员 | 通过命令行启动/停止服务，配置端口、数据目录与白名单 |

## 3. 功能需求

### 3.1 点位数据模型（CSV 字段）

| 字段 | 英文列名 | 说明 | 约束 |
| --- | --- | --- | --- |
| 点位名称 | `name` | 业务名称，文件内唯一 | 非空，≤64 字符 |
| 点位 IO 地址 | `io_address` | 如 `40001`、`%IW64`、`DB1.DBW0` | 非空，≤64 字符 |
| 地址类型 | `address_type` | `memory`（内存）/ `io`（IO）/ `constant`（常量） | 三选一 |
| 点位类型 | `point_type` | 数据类型 | `bool/int/uint/float/double/string` 五选一 |
| 读写属性 | `rw` | 读写属性 | `rw`（读写）/ `ro`（只读）/ `wo`（只写）三选一 |
| 描述 | `desc` | 备注说明 | ≤255 字符 |

### 3.2 接口能力（读、写 × 单、批 = 4 类操作 + 文件管理）

1. **单读**：按文件名 + 行索引读取一个点位。
2. **批量读**：按文件名 + 起始索引 + 数量分页读取若干点位（count=0 表示全量）。
3. **单写**：向指定文件写入一个点位；携带 `index` 为修改，不携带为追加。
4. **批量写**：一次提交多个点位，逐条按单写语义处理，返回逐条结果。
5. **文件管理（支撑能力）**：列出数据目录下全部 CSV 文件；新建空白 CSV 文件（写入标准表头）。

统一响应包络 `{code, message, data}`；错误返回带 `code/message/details` 的错误体。详细请求/响应结构见《02-方案设计.md》。

### 3.3 访问控制

- 白名单中间件，匹配维度为 **来源 IP**（支持单 IP、CIDR 网段、IPv6）与 **来源 Origin**（浏览器跨域请求的 Origin 头，支持前缀通配 `*`）。
- 配置文件驱动，支持运行期无法热载也可接受（重启生效）。
- 未命中白名单时拦截请求，返回 `403` 与统一错误体；请求不进入业务处理。

### 3.4 前端页面

- 仅使用原生标准 Web 技术（HTML5 / CSS3 / JavaScript ES6，无任何第三方库、无构建工具）。
- 功能：选择/新建 CSV 文件；表格展示点表；表单添加点位并写入 CSV；选中行编辑并保存；错误提示。
- 工业风格：深色低眩光配色、高对比、等宽数字字体、状态栏，适配车间触摸/远看场景。

### 3.5 CSV 存储要求

- 字段固定为 3.1 的 6 列，UTF-8（带 BOM，兼容 Excel 直接打开）。
- 文件存储于数据目录，命名规则与并发写入处理见《02-方案设计.md》第 5 节。

## 4. 非功能需求

| 项 | 要求 |
| --- | --- |
| 语言标准 | C++17 及以上（使用 `std::filesystem`、结构化绑定、`std::optional`、`std::shared_mutex` 等） |
| 依赖 | 仅限 `third_party` 目录下现有库：cpp-httplib、nlohmann/json、rapidcsv |
| 并发 | 服务多线程处理请求（httplib 线程池）；CSV 读写需线程安全，写操作原子落盘 |
| 部署 | Windows 优先（MinGW/MSVC 均可编译），单进程单端口 |
| 规模 | 单文件点表 ≤ 10 万行，接口响应 < 200ms（本机） |

## 5. 验收标准

1. 四类读写接口按《02-方案设计.md》定义可正常调用，成功/失败状态码与错误字段符合定义。
2. 白名单未命中来源访问任意接口返回 403 及统一错误体；命中来源正常访问。
3. 前端页面在浏览器中可新建 CSV、添加点位写入、编辑点位保存，全程无第三方库加载。
4. CSV 文件字段顺序为 6 列标准表头，可用 Excel 打开无乱码。
5. 并发批量写同一文件不出现数据丢失或文件损坏（临时文件 + 原子替换）。
